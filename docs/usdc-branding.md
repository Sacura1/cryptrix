# USDC asset provenance

frontend/public/brand/usdc.svg is the unmodified official Circle USDC Token Logo from Circle's pressroom brand kit (downloaded 2026-10-02).

Source: https://www.circle.com/pressroom
Asset package: https://6778953.fs1.hubspotusercontent-na1.net/hubfs/6778953/Pressroom/brandkit/logo-downloads/usdc.zip

The Usdc React component renders the official SVG at 32px with visible USDC text. Monetary amounts in stake cards, pots, wallet balances, limits, transaction reviews and payouts use it. Practice amounts remain explicitly simulated. The token identity uses its official blue; Cryptrix's interface keeps its warm game palette.
